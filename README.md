 KrmaVerso Store
Sitio estático listo para publicar con GitHub Pages.

## Archivos
- `index.html`: portada nueva de KrmaVerso Store.
- `tienda.html`: catálogo inicial por categorías con contacto WhatsApp.
- `juegos.html`: catálogo de juegos recuperado del sitio anterior.
- `aplicaciones.html`: catálogo de aplicaciones recuperado del sitio anterior.

## Publicación
1. Crea un repositorio público nuevo llamado `KrmaVerso-Store` en tu nueva cuenta de GitHub.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. En Settings → Pages, selecciona Deploy from a branch, rama `main`, carpeta `/ (root)`.
4. Guarda y espera la URL que GitHub Pages indique.
